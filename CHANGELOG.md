# ms7.vs2.0

## Установщик

- У установщика появилось окно. Раньше он работал молча: человек запускал
  файл, ничего не происходило, а через несколько секунд сама собой
  открывалась программа. Теперь видно, что идёт установка и на каком она
  шаге.
- Папку установки можно выбрать. Она проверяется до начала работы: если
  писать в неё без прав администратора нельзя (например, Program Files),
  мастер скажет об этом сразу, а не посреди распаковки.
- Установщик выпускается в двух видах. Обычный `MS7VPN-Setup.exe` весит
  около двух мегабайт и качает файлы программы с GitHub. Полный
  `MS7VPN-Setup-Full.exe` несёт всё внутри и ставит без интернета — для тех,
  у кого GitHub не открывается.
- Путь установки записывается в реестр и оттуда же читается при обновлении
  и удалении. Раньше он вычислялся заново, и после установки в другую папку
  обновление положило бы вторую копию в %LOCALAPPDATA%, а ярлыки продолжали
  бы вести на старую.
- Перед установкой новой версии папка программы очищается. Распаковка
  поверх оставляла файлы, которых в новой сборке уже нет. Настройки и
  подписки лежат в %APPDATA%\MS7VPN и не затрагиваются.
- Деинсталлятор переехал внутрь payload.zip: онлайн-установщик ничего не
  несёт внутри себя и берёт его оттуда же, откуда и остальное.

## Белое окно при первом запуске

- **Исправлено главное**: после установки программа открывалась с белым
  окном, а перезапуск с ярлыка всё лечил. Установщик запускал её с флагом
  `HideWindow`. Это не «скрыть консоль», а `SW_HIDE` в `STARTUPINFO`, и
  Windows передаёт это значение дочернему процессу как состояние его первого
  окна. WebView2 считал, что показывать нечего, и не рисовал. Флаг был ещё и
  бессмысленным: программа собрана с `-H windowsgui` и консоли не имеет.
- По той же причине установщик больше не запускается скрытым при
  автообновлении — иначе человек, нажав «Обновить», не увидел бы окна
  мастера.
- Страница сообщает программе, что ожила (`/api/ui-ready`). Прежняя проверка
  считала успехом сам факт отдачи HTML, а окно при этом могло остаться
  белым.
- Повторная навигация стала редкой: первая пауза пять секунд, дальше три
  попытки по три. Прежние двенадцать попыток по 0.7 секунды сносили
  страницу, которая уже почти отрисовалась, — повторы сами продлевали
  белое окно.
- Если окно так и не ожило, программа открывает запасной интерфейс вместо
  белого листа и запоминает это: следующий запуск идёт без видеоускорения.
- Профиль WebView2 переехал в `%APPDATA%\MS7VPN\webview2`. По умолчанию
  библиотека заводила папку с именем самого exe прямо в Roaming.
- Вывод стандартного журнала направлен в `ms7vpn.log`. Программа собрана без
  консоли, и раньше всё, что писала библиотека окна, включая `log.Fatal`,
  пропадало бесследно — белое окно нечем было объяснить. Туда же пишутся
  запросы страницы первых секунд.

## Обновление

- Программа обновляется сама. Кнопка в разделе «О программе» раньше просто
  открывала браузер, дальше человек ставил новую версию руками. Теперь
  программа скачивает установщик, показывает ход скачивания и передаёт ему
  работу: установщик закрывает программу, заменяет файлы и запускает её
  снова.
- Скачанные файлы проверяются по SHA-256. Контрольные суммы лежат в выпуске
  отдельными вложениями и запрашиваются только тогда, когда обновление
  действительно есть.
- Исправлено: адрес репозитория с `.git` на конце — а именно такой даёт
  кнопка «Code» на GitHub — превращался в запрос к несуществующему
  репозиторию, и проверка обновлений отвечала «сервер обновлений ответил
  404».
- Полная сборка `-Full.exe` при обновлении не выбирается: она весит в
  десять раз больше и ставит ровно то же самое.

## Сборка

- `BUILD_WINDOWS.bat` собирает оба установщика и готовит файлы выпуска:
  `MS7VPN-Setup.exe`, `MS7VPN-Setup-Full.exe`, `MS7VPN-payload.zip` и
  контрольную сумму к каждому.
- `mkpayload` умеет считать SHA-256: `mkpayload -sum ФАЙЛ`. Формат тот же,
  что у sha256sum.

## О номерах версий

Схема `ms7.vsМАЖОРНАЯ.МИНОРНАЯ` обязательна. Версии сравниваются по числам
в порядке появления, и цифра 7 из «ms7» тоже участвует: тег вида `v2.0` даёт
[2, 0] против [7, 1, 2] у `ms7.vs1.2`, и обновление не находится. На это есть
тест `TestNewerKeepsProjectScheme`.

## Подключение

- Убран прогон `xray run -test` из горячего пути. Он выполнялся перед каждым
  подключением и удваивал запуск ядра. Теперь запускается только если Xray
  не поднялся — чтобы вернуть настоящую причину вместо «завершился сразу
  после запуска».
- Убраны фиксированные паузы: 900 мс после старта Xray и 1200 мс перед
  проверкой TUN. Вместо них — опрос готовности с шагом 40–120 мс.
- Мьютекс менеджера больше не удерживается во время старта ядра. Раньше
  `/api/state` упирался в него, и окно переставало отвечать на всё время
  подключения.
- Настройки реестра (системный прокси) правятся через WinAPI вместо запуска
  `reg.exe`. На одно подключение приходилось больше восьми созданий процесса.
- `geoip:private` и `geosite:private` заменены на явные подсети и домены:
  geo-файлы на 29 МБ больше не читаются при каждом запуске.
- `domainStrategy` переведён с `IPIfNonMatch` на `AsIs`. При `IPIfNonMatch`
  Xray резолвил каждый домен ПЕРЕД маршрутизацией — лишний DNS-запрос на
  каждое соединение.
- В режиме системного прокси локальный резолвер больше не используется:
  имя хоста передаётся на сервер, который его и резолвит.
- В режиме TUN DNS переведён на DoH и заворачивается в туннель правилом
  `dns-in → proxy`. Обычный UDP/53 к 1.1.1.1 часто отбрасывается фильтром,
  и каждый домен ждал таймаут.
- Прямой outbound переведён с `UseIP` на `AsIs` — тоже минус один резолв
  на каждое прямое соединение.
- Порты 10808/10809 больше не зашиты: если заняты соседним клиентом
  (v2rayN, Nekoray), подбирается свободный.

## Надёжность

- Xray запускается в job object и гарантированно умирает вместе с
  приложением. Раньше упавший MS7VPN оставлял висеть `xray.exe`, который
  держал порты и сетевой адаптер.
- При старте убиваются осиротевшие `xray.exe` из нашей папки. Чужие копии
  Xray не трогаются — сверяется полный путь.
- `Stop()` дожидается фактического завершения процесса. Раньше следующий
  запуск успевал начаться до освобождения портов и адаптера.
- Системный прокси восстанавливается при старте, если прошлый сеанс
  завершился аварийно. Битая резервная копия больше не оставляет систему
  без интернета: прокси в этом случае просто выключается.
- Hysteria2 честно помечается неподдерживаемым. Такого протокола нет в
  Xray-core, и приложение собирало для него конфиг, который ядро отклоняло.
- `access.log` и `error.log` обрезаются по достижении 1 МБ. Раньше росли
  без ограничений.
- Признак готовности TUN-адаптера больше не срабатывает на слово `started`
  из посторонних строк журнала.

## Интерфейс

- Значок в области уведомлений: цвет по состоянию, подсказка с сервером и
  временем сеанса, контекстное меню (подключить/отключить, открыть окно,
  обновить подписку, выход), уведомления Windows о подключении, разрыве и
  ошибке. Раньше значка не было вообще.
- Крестик сворачивает окно в трей — с отдельной настройкой.
- Кнопки «Обновить» показывают результат: сколько серверов стало, сколько
  добавилось и убыло. Раньше они молчали.
- Обновление подписки доступно прямо с главного экрана.
- Список серверов обновляется «по месту», а не пересобирается целиком
  каждые 2,5 секунды: больше не сбрасывается прокрутка и не дёргается
  наведение.
- Фоновый опрос состояния больше не затирает результат действия
  пользователя устаревшим снимком.
- Заработали галочки «Обновлять подписки автоматически» и «Подключаться
  при запуске» — в окне WebView2 они не читались вообще.
- Настройка «Блокировать рекламу» больше не сбрасывается при каждом
  сохранении. Если `geosite.dat` рядом нет, правило пропускается с
  понятным предупреждением вместо отказа ядра запускаться.
- Единые значения по умолчанию: раньше HTTP-обработчик и нативное окно
  подставляли разный режим подключения.
- Название подписки больше не превращается в мусор: обычное имя вроде
  «MS7VPN» декодировалось как base64.

## Установщик и размер

- Запускается bootstrapper WebView2, если рантайма нет в системе. Раньше
  файл лежал внутри, но не запускался никогда.
- Файлы распаковываются потоком с проверкой размера. Прежняя версия читала
  файл целиком в память и при неверном заголовке ZIP молча писала обрезанный
  exe.
- Деинсталлятор стал отдельной программой на ~2 МБ вместо полной копии
  установщика на ~24 МБ.
- Удаляются хвосты прошлых версий: `Uninstall-MS7VPN.exe` и скачанная копия
  ядра в `%APPDATA%\MS7VPN\core` (около 63 МБ).
- `rmdir` при удалении получил `/s /q` — папка не оставалась на диске.
- `taskkill` больше не моргает консольным окном.
- Рабочий стол определяется с учётом перенаправления в OneDrive.

## Сборка

- Добавлены `go.sum` и `vendor/`: проект собирается офлайн. Прежняя версия
  ссылалась на коммит `go-webview2`, которого больше нет в репозитории, —
  собрать её с нуля было невозможно.
- `BUILD_WINDOWS.bat` собирает приложение, деинсталлятор, payload и
  установщик одной командой.
- Добавлены тесты: раскладка структур Win32, отсутствие geo-файлов в
  конфиге по умолчанию, DNS-политика для обоих режимов, отказ hysteria2,
  разбор названий подписок.

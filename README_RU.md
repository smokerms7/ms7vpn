# MS7VPN Desktop Native — 0.4.0-alpha.1

Нативная Windows-версия MS7VPN. Эта ветка больше не запускает Microsoft Edge и не использует браузер как окно приложения.

## Что изменено относительно старого прототипа

- Нативное окно Win32: в панели задач приложение определяется как **MS7VPN**, а не Microsoft Edge.
- Интерфейс полностью доступен до добавления подписки: Главная, Серверы, Подписки, Настройки, Журнал.
- Подписка добавляется во вкладке **Подписки** по URL или напрямую из буфера обмена.
- Remnawave import отправляет стабильный `X-Hwid` и Windows device headers; при HTTP 403 автоматически пробует Happ-compatible User-Agent.
- Серверы появляются только после успешного импорта пользовательской подписки.
- Сервер можно выбрать, добавить в избранное и проверить TCP latency.
- Подписку можно обновлять, обновлять все сразу и удалять.
- Реальное подключение запускает официальный Xray-core v26.3.27.
- Для TUN приложение использует Wintun 0.14.1. Если DLL нет в Xray archive, MS7VPN скачивает официальный подписанный Wintun и проверяет SHA-256.
- Статус **«Подключено»** ставится только после запуска Xray и успешного контрольного HTTP-запроса через созданный маршрут/proxy.
- Для TUN приложение само запрашивает перезапуск с правами администратора.
- Есть журнал процесса Xray и видимые сообщения об ошибках.

## Поддерживаемый импорт

- VLESS
- VMess
- Trojan
- Shadowsocks
- SOCKS5
- Hysteria2
- RAW/TCP, XHTTP, WebSocket, gRPC, HTTPUpgrade, mKCP
- TLS, REALITY, none — в допустимых комбинациях Xray
- Hysteria2 + TLS, включая Salamander obfs в конфигурации, которую поддерживает текущий builder

## Как тестировать

1. Запустите `MS7VPN.exe`.
2. Откройте **Подписки**.
3. Вставьте URL, выданный Telegram-ботом MS7VPN, и нажмите **+ Добавить**.
4. После успешного импорта откройте **Серверы** — там должны появиться только ноды из этой подписки.
5. Нажмите **Проверить пинг**, выберите сервер.
6. На **Главной** нажмите **Подключить**.
7. Для режима TUN подтвердите UAC. После перезапуска MS7VPN продолжит подключение автоматически.
8. Если соединение не проходит — откройте **Журнал** и пришлите текст ошибки.

## Важное

Это alpha для реального тестирования на вашем Windows-ПК. Кросс-сборка и unit-тесты проходят, но среда разработки здесь не запускает Windows GUI, поэтому конечный TUN надо проверить на настоящем Windows с вашей Remnawave-подпиской.

QR-сканирование в нативной ветке пока не перенесено. Сейчас рабочий путь — URL/буфер обмена. QR будет отдельным следующим модулем, чтобы не возвращаться к WebView/Edge.

## Сборка из исходников

Нужен Go 1.23+.

```powershell
$env:GOOS="windows"
$env:GOARCH="amd64"
$env:CGO_ENABLED="0"
go test ./...
go build -trimpath -ldflags="-H windowsgui -s -w" -o dist/MS7VPN.exe ./cmd/ms7vpn
```

## Внешние компоненты

- Xray-core v26.3.27 — скачивается приложением с официального GitHub release, SHA-256 проверяется.
- Wintun 0.14.1 — скачивается с официального wintun.net при необходимости, SHA-256 проверяется.
